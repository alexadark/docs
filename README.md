# Docs

Standalone HTML documents shared by Alexandra Spalato, served with GitHub Pages at https://alexadark.github.io/docs/.

- One folder per theme (`tamos/`, `kanban/`, ...), kebab-case file names.
- New pages start from `_template/linear-dark.html`.
- Add each page to `index.html` under its theme.
- Public repository: no private data, client names, prices or personal information.
