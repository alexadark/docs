House rules

  • One shared set of statuses: Inbox, Ready, In Progress, Waiting, Review, Done, Parked. Done really closes the task.
  • Reference material goes in Docs, not tasks.
  • An active task has an owner, a due date (or a deliberate "no date") and a "done when".
  • Nothing TAMOS lives in a private space.
