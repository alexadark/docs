Where we are

What the audit found

~1,270

parent tasks that look open, mostly template clones and old work

6+

different status sets, with "client review" and "in client review" side by side

3–5

places where the same client lives

"Closed" is set up as a done status that ClickUp still counts as open. That's why lists look much busier than they are, and why any automation built today would send noise.

Target

Spaces by function, not by client

The client becomes a record you link to, not a place you have to find.

Clients

One card per client: offer, services, contacts, Slack channel, preferences, approval history.

Delivery

One folder per active client, one list per project created from a template. Offer level becomes a field.

Support

Client and hosting tickets in a single flow.

Products

Internal product work, visible to the whole team.

Growth

Agency marketing and sales.

Archive

Everything dead, archived, never deleted.

One status set everywhere: Inbox → Ready → In Progress → Waiting → Review → Done (really closed) → Parked.
Working without waiting

Later, Claude connects to ClickUp, Slack and the SOPs so you can ask it to start a project from a template, check a handoff is complete, draft a follow-up or summarize a client. Only after the cleanup: on today's workspace it would repeat the mess.

Order

Seven steps

  1. Safe cleanup

    Archive dead spaces and empty lists, assign orphan tickets.

  2. Client cards

    One list, one card per client, clean up the client field.

  3. One status set

    A real closed "Done". Needed before any automation.

  4. SOPs and templates

    The table above, written with you.

  5. Automations

    ClickUp to Slack first, then Vimeo and YouTube descriptions.

  6. Merge Delivery

    Fold client tiers into one Delivery space, move product work to its own space.

  7. Claude for the team

    Start with one concrete job you asked for, like checking a handoff.
