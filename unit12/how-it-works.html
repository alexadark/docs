Where it all runs

New on November 23 and 24

All of these are in the code today.

Card guardrails

A topic that already has an open card gets a comment there, whatever source it came from. An agent can't start in a folder outside its project.

Follow-ups

A failed merge or test, a reply to a mail it drafted, a web task report or a failed send goes back to the agent that did the work.

Would have done

A rule an agent proposes, or a new automation, first only notes what it would have done. It acts once it's turned on. Your own rules apply at once.

Short answers

Chat replies stay within 100 words, with one question at a time.

Event wakes only

A due reminder or a recurring card wakes no PM. Shade's morning sweep lists both.

Honest WhatsApp light

Only a run that really read the messages counts. A refused one shows red, on its own row.

Try it in three steps

  1. See the board

    Follow Quick start in the README. You get the board on your Mac, with example projects and no agents.

  2. Connect Orca

    Follow docs/install.md from step 5. You need macOS, Orca, and Claude Code or Codex signed in.

  3. Write one card

    Pick something small, give it a clear Done when, and let a PM take it through the chain above.

Unit12 runs one person's work every day and isn't a packaged product yet. Read section 9 of the install guide before you give agents access to real accounts.
